# AI Problem Solving Assignment

## Problems Implemented

### 1. Tic-Tac-Toe AI
- Algorithm: Minimax
- AI always plays optimal move

### 2. BFS vs DFS Navigation
- Algorithms: BFS, DFS
- BFS finds shortest path
- DFS finds any path

## How to Run

Install dependencies:
pip install streamlit

Run TicTacToe:
python -m streamlit run TicTacToe/app.py

Run BFS/DFS:
python -m streamlit run BFS_DFS/app.py
